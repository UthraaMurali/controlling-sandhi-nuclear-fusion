# controlling-sandhi-nuclear-fusion

## Controlling Sandhi in Nuclear Fusion: Preventing Irreversible Commitment Before Ignition

Author: Uthraa Murali  
Affiliation: Independent Researcher, India  

### Abstract
This paper extends the Sandhi framework by introducing control mechanisms that prevent irreversible commitment before ignition in nuclear fusion systems. It formalizes Sandhi as a controllable intermediate causal state, enabling intervention, rollback, and safe termination prior to catastrophic ignition pathways.
